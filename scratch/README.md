# scratch/

One-off scripts, probes, and inspection snippets, kept runnable but outside the
verified core. This is the **default home for new AI-generated code** until it
earns a place in `src/`.

Nothing in `src/` or `scripts/` may import from `scratch/`.

- `multicot_archive/` — superseded v1 of the rollout pipeline (pre-rewrite, under its old `multicot` name), kept
  for reference only.
